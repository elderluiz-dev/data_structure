BILIOTECAS E FUNÇÕES - TRADUZINDO BINHOGOL PARA C

Antes de iniciarmos o arquivo principal vamos criar nosso arquivo que será a biblioteca. Bibliotecas em C nada mais são do que arquivos .h na raiz do arquivo principal, faremos para este exemplo binhogol.h, nele poderemos escrever as funções da nossa biblioteca.
Funções são blocos de códigos que podem ou não receber dados de outras funções (chamados de parametros), executam o código dentro deles e dão um retorno que pode ser usado em outras funções. Em C nossa função principal sempre se chama main e mesmo que seja a função de execução principal não deixa de ter as propriedades de uma função comum, pode receber argumentos e retornar um valor.
A respeito do valor a ser retornado, C exige que a função seja inicializada com o tipo de seu retorno, sendo assim, funções int devem obrigratóriamente retornarem um inteiro, funções float retornam um real e funções char retornam um caractere. Funções também podem não ter retorno, dessa forma seu tipo é void, que significa que é uma função que apenas executa algo, sem retornar nada para ser reutilizado.

Uma vez com a biblioteca criada vamos fazer o import da biblioteca padrão, lembrando que bibliotecas podem chamar outras bibliotecas, e fazer nossa primeira função para traduzir o o printf do C em leia do Binhogol. Aqui começamos a ver a necessidade dos parametros, uma vez que a função irá pegar algo de outra função para utilizar aqui, mas para entender sobre quais parametros passar precisamos criar nosso arquivo principal e entender um pouco sobre ponteiros para essa utilização.

Criei o arquivo principal, fiz o import da biblioteca padrão e iniciei a função main que é uma função do tipo int, não recebe nada como parametro e retorna 0, dentro de main vamos inicializar uma variável a que não recebe nada e vamos partir para a expliccação de ponteiros.
Ponteiros em C é uma forma de referenciar um espaço na memória, de forma que se torna acessivel de qualquer lugar do código, até mesmo em funções de fora da função em que a variável foi criada ou do arquivo em que ela está. Os ponteiros usam de dois caracteres para conversão, "&"  para referenciar um espaço na memória e "*" para acessar um espaço na memória, essa mesma lógica é usada com frequencia na função scanf onde referenciamos a variavel a ser lida com &(variavel), isso indica pra função sancf qual espaço da memória ele deve guardar o valor que foi lido e é exatamente deste recurso que vamos utilizar para transformar o scanf em leia.
